<objective>
Wrap PyBoy so the rest of the repo can boot Crystal, press buttons, and save or load a snapshot. This is the only mechanism layer.

This phase is the game substrate only. It does not include the PDF's later phases. Out of scope for every plan in `01-infrastructure`:

- Reinforcement learning: PPO, Worker B, action-effect head, visited mask, reward shaping, frontier buffer, shared-memory training pool, torch.
- Language-model director: planner, subgoal schema, SayCan, Eureka, knowledge-graph retriever, token or dollar accounting.
- Workers: A* autopilot, ghost scouts, combat model, battle search, interrupt router.
- Navigation memory database, NPC cache, ledge and grass costs.

The PDF's Phase 1 items that stay here: headless boot, banked RAM reads, a locked real-time clock, and a check that two runs given the same buttons end in the same memory. The 64-worker speed benchmark in that phase is training equipment and is not built.

Owner: Wave 1, parallel with 01-02.
</objective>

<context>
@CONTEXT.md
@crystal_smoke.py

PyBoy 2.8.1, already checked against the installed wheel:

- `PyBoy(gamerom, window="SDL2"|"null", symbols=path)`. `ram_file=None` loads `<gamerom>.ram` by itself.
- `tick(count=1, render=True) -> bool`. False when the window is closed.
- `button_press`, `button_release`. Names: up down left right a b start select.
- `save_state` / `load_state` take a file-like object (`io.BytesIO`).
- `set_emulation_speed(0)` is unlimited. `symbol_lookup(name) -> (bank, addr)`.
- `memory[bank, addr]` for 0xD000–0xDFFF. `memory[addr]` otherwise.
- `screen.image` is a 160×144 PIL image. Copy it before storing.
- `rtc_lock_experimental(True)` freezes the cartridge clock. Without it, reloads drift with wall-clock time.
- `stop(save=False)` so we never overwrite `rom/*.ram`.

Contract (later plans import these names):

- `src/config.py`: `ROOT`, `ROM_PATH`, `SYM_PATH`, `RAM_PATH` (ROM path + `.ram`), `ROM_SHA1 = "f2f52230b536214ef7c9924f483392993e226cfb"`, `STATES_DIR`, `MANIFEST_PATH`, `RUNS_DIR`. `sha1_file(path)`, `sha1_bytes(b)`.
- `src/emulator.py`:
  - `BUTTONS = ("up","down","left","right","a","b","start","select")`
  - `InputEvent(frame, button, kind)` with kind `"press"` or `"release"`.
  - `Machine` is a `typing.Protocol`: `frame`, `tick`, `press`, `hold`, `release`, `save_state`, `load_state`, `read`, `symbol`, `screen_image`, `add_listener`.
  - `Emulator` holds a PyBoy instance. It does not subclass PyBoy. Constructor: `Emulator(rom=ROM_PATH, sym=SYM_PATH, *, headless=True, speed=None, verify_rom=True, rtc_lock=True)`.
  - `RomMismatchError`.
  - `set_time_of_day("MORN"|"DAY"|"NITE")` and `seed_rng(add: int, sub: int)`. Both resolve `wTimeOfDay`, `hHours`, `hRandomAdd`, `hRandomSub` through `symbol()` and write those bytes. No hex literals in the public methods.
</context>

<task type="auto" tdd="true">
  <name>Task 2: Emulator, clock, matching runs</name>
  <files>src/emulator.py, tests/test_emulator.py</files>
  <behavior>
    - A temp file with the wrong bytes raises RomMismatchError before PyBoy starts.
    - Headless `tick(300)` leaves `frame == 300`.
    - `save_state()` bytes, then more ticks, then `load_state` restores the 256 bytes at bank 1 address 0xD000 and sets `frame` back to 0.
    - `press("a", frames=5)` emits press at frame 0 and release at frame 5. Unsubscribe stops further events.
    - Unknown button raises ValueError.
    - `screen_image().size == (160, 144)`.
    - `read` of a 0xD000-range address uses the bank form.
    - Two emulators, both `rtc_lock=True`, same `seed_rng`, same 50 button presses: the 256-byte bank-1 dump matches.
    - `set_time_of_day` writes the resolved `wTimeOfDay` byte (0 morning, 1 day, 2 night) and does not contain a hardcoded address.
  </behavior>
  <action>
Implement the contract. Default speed is 0 when headless and 1 when windowed. Call `rtc_lock_experimental(True)` after construction and after every `load_state` when `rtc_lock` is set. `load_state` resets the frame counter so recordings are relative to the snapshot. `press` is hold, tick, release. `read` uses `memory[bank, addr]` inside 0xD000–0xDFFF and `memory[addr]` otherwise. `close` calls `stop(save=False)` and is safe to call twice.

`set_time_of_day` also writes `hHours` to 8, 12, or 20 for morning, day, and night. `seed_rng` writes the two random bytes. Tests use unittest. Skip ROM tests when the ROM file is missing. Boot once per class.
  </action>

    <automated>.venv/bin/python -m unittest tests.test_emulator -v</automated>
  </verify>
