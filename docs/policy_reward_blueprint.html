Policy and Reward Blueprint

How the agent would play the early game end to end: who presses the buttons in each situation, and which rewards teach the one part that learns. Values come from src/rl_env.py; anything not in the code today is marked new.

Who acts

What the walking policy sees

5×5 local grid and blocked-tile mask, last action, HP fraction, party size and top level, battle and dialogue flags. New: stage one-hot (or the event flags), the first step of the shortest path to the current goal, and remaining distance to that goal.

Why the stage must be in the input

Route 30 is walked north to Mr. Pokémon, south with the egg, and north again to Violet. Without the stage, one tile asks for three different directions.

Build order

  1. Merge return_nav and falkner_nav into one route graph with warps, and compute Φ(stage, tile).
  2. Add stage, next-step direction and remaining distance to the observation.
  3. Swap the hand-coded potentials for route progress at 0.08 per step, and delete the per-map waypoints.
  4. Cut new-tile and neighbor bonuses when a route graph covers the map.
  5. Make the finished-map penalty stage-aware so the egg return is allowed.
  6. Test: Φ rises along the path, including across each goal; a full circle telescopes to the end value; the same tile gives different features at stage 1 and stage 3.
  7. Train from stage-balanced start states with the entropy schedule, and compare steps-to-goal per leg against the scripted navigators.
